# libjpeg-turbo G3：RVV SIMD 后端功能验收（2026-11-14）

上游 `simd/riscv64/` 已自带完整 RVV 后端（16 个内核文件）：

```
jfdctfst-rvv  jfdctint-rvv  jidctfst-rvv  jidctint-rvv  jquanti-rvv
jccolor-rvv   jcgray-rvv    jcgryext-rvv  jccolext-rvv
jdcolor-rvv   jdmerge-rvv   jdmrgext-rvv  jdcolext-rvv
jcsample-rvv  jdsample-rvv  jsimdcpu.c / jsimdcpu.S
```

| 侧 | 配置 |
|---|---|
| A | `WITH_SIMD=ON`，`-march=rv64gcv` |
| B | `WITH_SIMD=OFF`，同一 `-march=rv64gcv` |

| 项 | A | B |
|---|---|---|
| 压缩码流 | `jpeg=2799 fnv_jpeg=f0dd2e9ada7876e4` | 同左 |
| 解码像素 | `fnv_px=79887ab513b04ba1` | 同左 |

**码流与像素都逐字节相同**——这不是巧合：libjpeg-turbo 的 SIMD 内核按"与 C 参考实现逐位一致"设计，
ISLOW 整数 IDCT 与定点色彩转换都是精确整数运算，向量化不改变舍入。

真机性能：`build/rvv-k/{on,off}/bench`（1024x768 RGB 压缩 + 解压，q=90），
`scripts/board-ab.sh libjpeg-turbo <board>` 在板上跑。
